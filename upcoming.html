Task Panda

Made with React Native and SQL (soon to incorporate AWS)

Initially, I started the app to help myself with task management, but the issue goes way past just me. The app will feature a full tech stack using AWS for authentication and object storage, while using PostgreSQL for the database.

Completing tasks is basic, but people need a structured way to complete things in their life without burnout. Task Panda will offer many features to help you focus on whats important, while having fun in our interactive Panda Simulator. Task Panda offers features such as Hanging Deadlines, Schedule Automater, Ramble, and more features centered around students.
