Task Panda

React Native TypeScript PostgreSQL AWS S3 AWS Cognito SQL Kotlin (soon) Swift

Initially, I started the app to help myself with task management, but the issue goes way past just me. The app will feature a full tech stack using AWS for authentication and object storage, while using PostgreSQL for the database.

Completing tasks is basic, but students need a structured way to complete their school life without burnout. We help you become more focused on what matters, and realize what holds you back. Task Panda offers features such as Hanging Deadlines, Schedule Automater, Ramble, and more features centered around students.
