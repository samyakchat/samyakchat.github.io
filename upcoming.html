Initially, I started the app to help myself with task management, but the issue goes way past just me. The app will feature a full tech stack using AWS for authentication and object storage, while using PostgreSQL for the database.

Completing tasks is basic, but students need a structured way to complete their school life without burnout. We help you become more focused on what matters, and realize what holds you back. Task Panda offers features such as Annoying Meter, Exam Reflection, Syllabus Planner, Ask Panda, and more features centered around students, and helping them improve their academic life.

Based on research by Kamei and others, JIT defect prediction is an already improved method of safeguarding commits, however committer brings an easier, faster, and more predictive model to programmers. Judging given values like unit complexity and unit interface values, along with inferencing other metadata, allows us to properly judge whether a commit is safe or not.

More focused on metadata, it's learned off of many repos to recognize patterns and protect users' code. It's use case is a VS Code extension where it would provide developers with feedback in their output console telling them, "This commit isn't safe, or will break XYZ".
