Task Panda

Made with React Native and SQL

Currently, the app is used to teach me React Native with Expo, where I will add new and better features as I develop. The Add Task button is temporary.
Completing tasks is basic, but people need a structured way to complete things in their life without burnout. Task Panda (will) offer many features to help you focus on whats important, while having fun in our interactive Panda Simulator. The app will have a strucutre where you add tasks and brain dump all the things you have for the next day, they will then be assigned. You can also create goals with a similar structure.

Ideal Homescreen

This is what you will see every day when completing tasks. You can have color tags, and repeating tasks.

Repeating Tasks

When you enable repeating tasks (Every day, or 2 days or week), they show with the symbol.

Goal Screen

This is the goal screen where your current goal is laid out in steps you complete.

SubHub

Made with SwiftUI, SQL


To learn SwiftUI, I created SubHub as a simple subscription manager.
Do you struggle with keeping up with subscriptions you didnt know you had? Subhub makes it easy to see these and pay so you don't waste money on subscriptions you don't need. For me, I used SubHub to learn how to use SQL on Swift, as well as learn SwiftUI in general.

Add Modal

This is a modal where you fill out parameters for a subscription.

Main Screen

This is where you view subscriptions organized by priotity.

Edit Mode

Like in any IOS app, you can remove subscriptions
