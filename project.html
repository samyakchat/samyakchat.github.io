Project Whisper

HTML javascript CSS Websocket
2025
GitHub

Project Whisper is a hackathon project built around a World War II–style secure communication scenario. Inspired by systems like Enigma and Allied ciphers, it lets users encrypt and decrypt messages to simulate protecting sensitive information from interception. The platform includes a REST API, real-time messaging, multiple encryption methods, and an “intercept” feature that mirrors wartime intelligence operations.
